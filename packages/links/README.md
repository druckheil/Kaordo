# Kaordo links

Canonical root-relative routes shared across Kaordo applications.

Future cross-module object links belong here when their URL contract is defined.

The current exports provide `appPaths` and typed application IDs/paths. Object hashes, selected-object return history and app-local views remain in their owning app until a shared URL contract is introduced. Do not move app interaction state here. See [architecture](../../docs/architecture.md).
